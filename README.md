# Zach Mere academic website

This is a static website, so it can be hosted on GitHub Pages, Netlify, or any standard web server.

## Preview locally

Open `index.html` in a browser, or run a local server from this directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Update content

- Edit page content in `index.html`.
- Edit colors and layout in `styles.css`.
- Replace `MereCV.pdf` with an updated file using the same filename to preserve the CV links.

The only external resource is the Google Fonts stylesheet. If it does not load, the site falls back to Georgia and the system sans-serif font.
